# Verilator — Fast Open-Source SystemVerilog Simulator

Verilator is the fastest open-source simulator for Verilog and SystemVerilog. It compiles RTL into optimized C++ (or SystemC), then compiles that to native machine code. The result: **100–1000× faster** than interpreted simulators like Icarus Verilog, and often faster than commercial event-driven simulators for synthesizable designs.

This article covers installation, the compilation flow, C++ testbench authoring, tracing, coverage, linting, multi-threaded simulation, cocotb integration, CI/CD, and best practices.

---

## How Verilator Works

Verilator is not an event-driven simulator. It performs **cycle-based simulation**: at each clock edge, it evaluates all combinational logic and updates all state in a deterministic order. This eliminates the event queue overhead that slows interpreted simulators.

```
Verilog/SV source
       │
       ▼
┌──────────────┐     ┌───────────────────┐     ┌──────────────┐
│  Verilator   │     │  C++ Compiler     │     │  Native ELF  │
│  (frontend)  │────►│  (g++/clang++)    │────►│  (executable)│
│  AST + lint  │     │  -O3 optimization │     │  + Vtop.so   │
└──────────────┘     └───────────────────┘     └───────┬──────┘
                                                       │
                                                  ┌────▼────┐
                                                  │  Run    │
                                                  │  sim    │
                                                  └─────────┘
```

**Consequences of cycle-based design:**
- No `#delays` in testbenches (use `eval()` on clock edges)
- No `initial` blocks with delays (Verilator converts to C++, not event queue)
- No X/Z states (everything is 0 or 1 — 2-state simulation)
- No `force`/`release` (not synthesizable)
- No UVM, classes, or dynamic allocation in RTL (only synthesizable SV subset)

## Compilation Flow

### Basic Flow

```bash
# Step 1: Compile Verilog → C++, build executable
verilator --cc --build -j 0 top.v --exe tb.cpp

# Step 2: Run
./obj_dir/Vtop
```

### Key Command-Line Options

| Option | Purpose |
|---|---|
| `--cc` | Generate C++ output (default) |
| `--sc` | Generate SystemC output |
| `--build` | Auto-compile C++ to executable (calls g++/clang++) |
| `-j 0` | Use all CPU cores for C++ compilation |
| `--exe tb.cpp` | Link testbench C++ file |
| `--trace` | Enable VCD waveform tracing |
| `--trace-fst` | Enable FST waveform tracing (faster, compressed) |
| `--trace-saif` | Enable SAIF power estimation tracing |
| `--coverage` | Enable all coverage (line + toggle + branch) |
| `--coverage-line` | Line coverage only |
| `--coverage-toggle` | Toggle coverage only |
| `--coverage-branch` | Branch coverage only |
| `--lint-only` | Lint without generating C++ |
| `--threads 4` | Multi-threaded simulation (4 threads) |
| `--top-module top` | Explicitly set top module |
| `--Mdir obj_dir` | Output directory (default: `obj_dir/`) |
| `--Wall` | Enable all warnings (recommended) |
| `-DDEFINE=value` | Pass preprocessor define |
| `-I dir` | Include directory for Verilog files |
| `--f filelist.f` | Read file list from file |
| `--x-assign 0` | How to treat X in assignments (0, 1, fast) |
| `--no-timing` | Ignore timing constructs (for synthesis-only RTL) |

## C++ Testbench Authoring

### Basic Structure

Every Verilator C++ testbench follows this pattern:

```cpp
#include "Vtop.h"          // Auto-generated by Verilator
#include "verilated.h"     // Verilator runtime

int main(int argc, char** argv) {
    // 1. Initialize Verilator
    Verilated::commandArgs(argc, argv);

    // 2. Create DUT instance
    Vtop* dut = new Vtop;

    // 3. Stimulus loop
    dut->rst = 1;
    for (int cycle = 0; cycle < 100; cycle++) {
        dut->clk = 0;
        dut->eval();
        dut->clk = 1;
        dut->eval();
    }

    // 4. Cleanup
    dut->final();           // Simulation cleanup
    delete dut;
    return 0;
}
```

### Clock and Reset Helper

```cpp
void tick(Vtop* dut) {
    dut->clk = 0;
    dut->eval();
    dut->clk = 1;
    dut->eval();
}

void reset(Vtop* dut, int cycles = 5) {
    dut->rst = 1;
    for (int i = 0; i < cycles; i++) tick(dut);
    dut->rst = 0;
    tick(dut);  // One more tick after reset deassert
}
```

### Example: Full Counter Testbench with Self-Check

```cpp
// tb_counter.cpp
#include "Vcounter.h"
#include "verilated.h"
#include <cstdio>
#include <cstdlib>

static Vcounter* dut;
static vluint64_t sim_time = 0;

void tick() {
    dut->clk = 0;
    dut->eval();
    dut->clk = 1;
    dut->eval();
    sim_time++;
}

int main(int argc, char** argv) {
    Verilated::commandArgs(argc, argv);
    dut = new Vcounter;

    // Reset
    dut->rst = 1;
    dut->en = 0;
    for (int i = 0; i < 5; i++) tick();
    dut->rst = 0;
    tick();

    // Test: count up
    dut->en = 1;
    for (uint32_t expected = 1; expected <= 200; expected++) {
        tick();
        if (dut->count != expected) {
            printf("FAIL at cycle %lu: expected %u, got %u\n",
                   (unsigned long)sim_time, expected, dut->count);
            delete dut;
            return 1;
        }
    }

    // Test: disable should freeze count
    dut->en = 0;
    uint32_t frozen = dut->count;
    tick();
    if (dut->count != frozen) {
        printf("FAIL: count changed while disabled\n");
        delete dut;
        return 1;
    }

    // Test: reset clears count
    dut->rst = 1;
    tick();
    if (dut->count != 0) {
        printf("FAIL: reset didn't clear count\n");
        delete dut;
        return 1;
    }

    printf("PASS: All counter tests passed\n");
    dut->final();
    delete dut;
    return 0;
}
```

```verilog
// counter.v
module counter (
    input  logic        clk,
    input  logic        rst,
    input  logic        en,
    output logic [31:0] count
);
    always_ff @(posedge clk)
        if (rst)        count <= 0;
        else if (en)    count <= count + 1;
endmodule
```

```bash

./obj_dir/Vcounter
# Output: PASS: All counter tests passed
```

## Example: FIFO Testbench with Waveform Tracing

```cpp
// tb_fifo.cpp
#include "Vfifo.h"
#include "verilated.h"
#include "verilated_vcd_c.h"  // VCD tracing
#include <cstdio>
#include <cstdlib>

static Vfifo* dut;
static VerilatedVcdC* tfp;
static vluint64_t sim_time = 0;

void tick() {
    dut->clk = 0;
    dut->eval();
    if (tfp) tfp->dump(sim_time * 2);
    dut->clk = 1;
    dut->eval();
    if (tfp) tfp->dump(sim_time * 2 + 1);
    sim_time++;
}

int main(int argc, char** argv) {
    Verilated::commandArgs(argc, argv);
    dut = new Vfifo;

    // Enable VCD tracing
    Verilated::traceEverOn(true);
    tfp = new VerilatedVcdC;
    dut->trace(tfp, 99);      // Depth 99 = trace all levels
    tfp->open("fifo.vcd");

    // Reset
    dut->rst_n = 0;
    dut->wr_en = 0;
    dut->rd_en = 0;
    dut->wr_data = 0;
    for (int i = 0; i < 5; i++) tick();
    dut->rst_n = 1;
    tick();

    int errors = 0;

    // Write 16 values
    for (int i = 0; i < 16; i++) {
        dut->wr_en = 1;
        dut->wr_data = i;
        tick();
    }
    dut->wr_en = 0;
    tick();

    // Check full flag
    if (!dut->full) {
        printf("FAIL: FIFO should be full after 16 writes\n");
        errors++;
    }

    // Read all values back
    for (int i = 0; i < 16; i++) {
        dut->rd_en = 1;
        tick();
        if (dut->rd_data != (uint8_t)i) {
            printf("FAIL: Read %u, expected %d\n", dut->rd_data, i);
            errors++;
        }
    }
    dut->rd_en = 0;
    tick();

    // Check empty flag
    if (!dut->empty) {
        printf("FAIL: FIFO should be empty after 16 reads\n");
        errors++;
    }

    if (errors == 0)
        printf("PASS: FIFO test passed\n");
    else
        printf("FAIL: %d errors\n", errors);

    tfp->close();
    dut->final();
    delete tfp;
    delete dut;
    return errors ? 1 : 0;
}
```

```verilog
// fifo.v — Simple synchronous FIFO
module fifo #(
    parameter WIDTH = 8,
    parameter DEPTH = 16
)(
    input  logic             clk,
    input  logic             rst_n,
    input  logic             wr_en,
    input  logic [WIDTH-1:0] wr_data,
    input  logic             rd_en,
    output logic [WIDTH-1:0] rd_data,
    output logic             full,
    output logic             empty
);
    localparam ADDR_W = $clog2(DEPTH);

    logic [WIDTH-1:0] mem [DEPTH];
    logic [ADDR_W:0]  wr_ptr, rd_ptr;

    assign full  = (wr_ptr[ADDR_W] != rd_ptr[ADDR_W]) &&
                   (wr_ptr[ADDR_W-1:0] == rd_ptr[ADDR_W-1:0]);
    assign empty = (wr_ptr == rd_ptr);
    assign rd_data = mem[rd_ptr[ADDR_W-1:0]];

    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            wr_ptr <= 0;
            rd_ptr <= 0;
        end else begin
            if (wr_en && !full) begin
                mem[wr_ptr[ADDR_W-1:0]] <= wr_data;
                wr_ptr <= wr_ptr + 1;
            end
            if (rd_en && !empty) begin
                rd_ptr <= rd_ptr + 1;
            end
        end
    end
endmodule
```

```bash
verilator --cc --build --Wall --trace -j 0 fifo.v --exe tb_fifo.cpp
./obj_dir/Vfifo
# Output: PASS: FIFO test passed

# View waveform
gtkwave fifo.vcd &
```

## Example: AXI-Lite Slave Testbench with BFM

```cpp
// tb_axi_lite.cpp
#include "Vaxi_lite_slave.h"
#include "verilated.h"
#include "verilated_vcd_c.h"
#include <cstdio>

static Vaxi_lite_slave* dut;
static VerilatedVcdC* tfp;
static vluint64_t sim_time = 0;

void tick() {
    dut->clk = 0; dut->eval();
    if (tfp) tfp->dump(sim_time * 2);
    dut->clk = 1; dut->eval();
    if (tfp) tfp->dump(sim_time * 2 + 1);
    sim_time++;
}

// AXI-Lite write BFM
void axi_write(uint32_t addr, uint32_t data) {
    // AW channel
    dut->awvalid = 1;
    dut->awaddr  = addr;
    dut->wvalid  = 1;
    dut->wdata   = data;
    dut->wstrb   = 0xF;
    while (!dut->awready) tick();
    tick();
    dut->awvalid = 0;
    while (!dut->wready) tick();
    tick();
    dut->wvalid = 0;

    // B channel
    while (!dut->bvalid) tick();
    if (dut->bresp != 0)
        printf("WARNING: Write @0x%08X returned SLVERR\n", addr);
    tick();
    dut->bready = 1;
    tick();
    dut->bready = 0;
}

// AXI-Lite read BFM
uint32_t axi_read(uint32_t addr) {
    dut->arvalid = 1;
    dut->araddr  = addr;
    while (!dut->arready) tick();
    tick();
    dut->arvalid = 0;

    while (!dut->rvalid) tick();
    uint32_t data = dut->rdata;
    dut->rready = 1;
    tick();
    dut->rready = 0;
    return data;
}

int main(int argc, char** argv) {
    Verilated::commandArgs(argc, argv);
    dut = new Vaxi_lite_slave;

    Verilated::traceEverOn(true);
    tfp = new VerilatedVcdC;
    dut->trace(tfp, 99);
    tfp->open("axi_lite.vcd");

    // Reset
    dut->rst_n = 0;
    dut->awvalid = 0; dut->wvalid = 0; dut->arvalid = 0;
    dut->bready = 0;  dut->rready = 0;
    for (int i = 0; i < 5; i++) tick();
    dut->rst_n = 1;
    tick();

    // Write then readback
    axi_write(0x00, 0xDEADBEEF);
    axi_write(0x04, 0x12345678);

    uint32_t r0 = axi_read(0x00);
    uint32_t r1 = axi_read(0x04);

    int errors = 0;
    if (r0 != 0xDEADBEEF) { printf("FAIL: reg0 = 0x%08X\n", r0); errors++; }
    if (r1 != 0x12345678) { printf("FAIL: reg1 = 0x%08X\n", r1); errors++; }

    printf("%s: AXI-Lite test %s\n", errors ? "FAIL" : "PASS",
           errors ? "failed" : "passed");

    tfp->close();
    dut->final();
    delete tfp;
    delete dut;
    return errors ? 1 : 0;
}
```

## Tracing (Waveforms)

### VCD Tracing

```bash
# Compile with --trace
verilator --cc --build --trace -j 0 top.v --exe tb.cpp
./obj_dir/Vtop
# Produces: dump.vcd (or filename set in tb)
```

### FST Tracing (Fast Signal Trace — Recommended)

FST is 10–50× more compact than VCD and loads faster in GTKWave:

```cpp
// In tb.cpp, replace VCD with FST:
#include "verilated_fst_c.h"  // FST tracing

// Replace VerilatedVcdC with VerilatedFstC:
VerilatedFstC* tfp = new VerilatedFstC;
dut->trace(tfp, 99);
tfp->open("wave.fst");
```

```bash
verilator --cc --build --trace-fst -j 0 top.v --exe tb.cpp
./obj_dir/Vtop
# Produces: wave.fst

gtkwave wave.fst &
```

### Selective Tracing (Performance)

Tracing all signals is expensive. For long simulations, trace only specific signals:

```cpp
// After dut->trace(tfp, 99), add:
dut->trace(tfp, 1);  // Depth 1 = top-level ports only
// For deeper: use tfp->open() + manual signal adding
```

## Coverage Collection

Verilator supports line, toggle, and branch coverage:

```bash
# Enable all coverage
verilator --cc --build --coverage -j 0 top.v --exe tb.cpp
./obj_dir/Vtop
# Produces: coverage.dat

# Generate human-readable report
verilator_coverage coverage.dat
# Shows per-file coverage percentages
```

### Coverage Types

| Type | What It Measures | Option |
|---|---|---|
| **Line** | Which lines of Verilog were executed | `--coverage-line` |
| **Toggle** | Which signals transitioned 0→1 and 1→0 | `--coverage-toggle` |
| **Branch** | Which branches of if/case were taken | `--coverage-branch` |

### Merging Coverage from Multiple Runs

```bash
# Run multiple tests
./obj_dir/Vtop +test=test1   # → coverage_test1.dat
./obj_dir/Vtop +test=test2   # → coverage_test2.dat

# Merge
verilator_coverage --merge coverage_merged.dat \
    coverage_test1.dat coverage_test2.dat

# Report
verilator_coverage coverage_merged.dat
```

## Linting

Verilator's linter catches synthesis and style issues **before** you even write a testbench:

```bash
verilator --lint-only --Wall top.v
```

### Common Lint Warnings

| Warning | Meaning | Fix |
|---|---|---|
| `UNUSED` | Signal declared but never used | Remove or add `/* verilator lint_off UNUSED */` |
| `UNDRIVEN` | Signal declared but never assigned | Add driver or default value |
| `UNOPTFLAT` | Combinational loop detected | Break loop with register or `/* verilator lint_off UNOPTFLAT */` |
| `WIDTH` | Bit width mismatch in assignment | Explicitly size with `'0` or cast |
| `CASEINCOMPLETE` | Missing case default | Add `default:` clause |
| `BLKSEQ` | Blocking assignment in sequential block | Use `<=` (non-blocking) in `always_ff` |
| `SYNCASPSET` | Async reset used in sensitivity as set | Check async reset polarity |
| `TIMESCALEMOD` | Timescale mismatch | Use `` `timescale 1ns/1ps `` consistently |

### Per-Line Lint Suppression

```verilog
always_ff @(posedge clk)
    if (rst) count <= 0;         /* verilator lint_off SYNCASPSET */
    else     count <= count + 1; /* verilator lint_on  SYNCASPSET */
```

### Lint-Only CI Gate

```yaml
# GitHub Actions: lint gate
- name: Verilator Lint
  run: |
    verilator --lint-only --Wall -Isrc src/*.sv
    # Exit code 0 = clean, non-zero = issues found
```

## Multi-Threaded Simulation

Verilator can partition the design across multiple OS threads for parallel evaluation:

```bash
verilator --cc --build --threads 4 -j 0 top.v --exe tb.cpp
./obj_dir/Vtop
```

### Thread Scaling Reality

| Threads | Speedup vs 1 thread | Notes |
|---|---|---|
| 1 | 1.0× | Baseline |
| 2 | 1.3–1.6× | Good for designs with natural partition |
| 4 | 1.5–2.2× | Diminishing returns; inter-thread sync overhead |
| 8 | 1.8–2.5× | Only beneficial for very large designs |

**Guideline:** Use `--threads 2` or `4` for designs > 50K LUTs. For small designs, single-threaded is faster (no synchronization overhead).

## Verilator + cocotb (Python Testbench)

If you prefer Python testbenches but want Verilator's speed:

```python
# test_fifo.py
import cocotb
from cocotb.clock import Clock
from cocotb.triggers import RisingEdge, ReadOnly

@cocotb.test()
async def test_fifo_rw(dut):
    cocotb.start_soon(Clock(dut.clk, 10, units='ns').start())

    # Reset
    dut.rst_n.value = 0
    dut.wr_en.value = 0
    dut.rd_en.value = 0
    await RisingEdge(dut.clk)
    await RisingEdge(dut.clk)
    dut.rst_n.value = 1

    # Write
    for i in range(16):
        dut.wr_en.value = 1
        dut.wr_data.value = i
        await RisingEdge(dut.clk)
    dut.wr_en.value = 0
    await RisingEdge(dut.clk)

    assert dut.full.value == 1, "FIFO should be full"

    # Read
    for i in range(16):
        dut.rd_en.value = 1
        await RisingEdge(dut.clk)
        await ReadOnly()
        assert dut.rd_data.value == i, f"Expected {i}, got {dut.rd_data.value}"
    dut.rd_en.value = 0
    await RisingEdge(dut.clk)

    assert dut.empty.value == 1, "FIFO should be empty"
```

## Best Practices

### 1. Always Use `--Wall`

```bash
verilator --cc --build --Wall -j 0 top.v --exe tb.cpp
```

Warnings catch real bugs. Don't suppress globally — fix or add targeted `lint_off`.

### 2. Reset All Inputs Before First eval()

```cpp
// GOOD: all inputs defined before eval()
dut->rst = 1;
dut->clk = 0;
dut->en  = 0;
dut->eval();   // No uninitialized signals

// BAD: some inputs undefined
dut->rst = 1;
dut->eval();   // en is undefined → garbage propagation
```

Verilator is 2-state: undefined = 0, not X. But relying on default-0 can hide bugs that would show as X in other simulators.

### 3. Use FST Instead of VCD for Large Designs

```bash
# VCD: 1 GB waveform file for 1M cycle sim
verilator --cc --build --trace ...

# FST: ~20-50 MB for same simulation
verilator --cc --build --trace-fst ...
```

### 4. Separate Build and Run in CI

```bash
# Build step (slow, cached in CI)
verilator --cc --build -j 0 top.v --exe tb.cpp

# Run step (fast, many test configurations)
./obj_dir/Vtop +test=smoke
./obj_dir/Vtop +test=regression
./obj_dir/Vtop +test=stress
```

### 5. Use File Lists for Large Designs

```bash
# filelist.f
src/top.sv
src/fifo.sv
src/uart.sv
src/spi.sv
+define+SIMULATION
+incdir+include
```

```bash
verilator --cc --build -j 0 -f filelist.f --exe tb.cpp
```

### 6. Handle Time with sim_time, Not Real Time

```cpp
// Good: use simulation cycle counter
vluint64_t sim_time = 0;
void tick() { /* ... */ sim_time++; }

// Bad: using real time or sleep
// Verilator doesn't model real time — it's cycle-based
```

### 7. Detect End of Simulation Gracefully

```cpp
if (Verilated::gotFinish()) {
    // $finish was called in Verilog
    printf("Simulation ended via $finish\n");
}
```

## Limitations and Workarounds

| Limitation | Impact | Workaround |
|---|---|---|
| **No X/Z** | Can't detect uninitialized state bugs | Use `--x-assign unique` to randomize X behavior; lint catches most issues |
| **No timing** | No SDF back-annotation | Use Vivado XSim or Questa for timing sim; Verilator for functional only |
| **No UVM** | Can't run UVM testbenches | Use cocotb + Verilator for Python-based verification; UVM on Questa for tapeout |
| **No `#delays`** | Can't model gate delays | Use cycle-accurate models instead; add `--no-timing` to ignore timing constructs |
| **SV subset only** | No classes, dynamic arrays, interfaces in some modes | Keep RTL synthesizable; put testbench logic in C++ or cocotb |
| **No VHDL** | Can't simulate VHDL directly | Use GHDL for VHDL, or convert VHDL→Verilog via GHDL `--synth` |
